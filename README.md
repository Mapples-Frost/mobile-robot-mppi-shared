# mobile-robot-mppi-shared

This repository is for curated milestone results, selected figures, summary notes, and collaborative writing materials for our mobile robot MPPI study.

## Purpose

This is a shared repository for:
- milestone-level experiment summaries
- selected figures and trajectory visualizations
- method notes and consolidated findings
- collaborative writing materials for reports, presentations, and manuscripts

This repository is **not** for raw daily exploration or unfinished personal experiments.

## Relationship to Personal Study Repositories

Each member maintains a separate personal study repository for:
- exploratory scripts
- trial-and-error implementations
- weekly learning logs
- intermediate notes and debugging records

Only curated and stage-level materials should be moved into this shared repository.

## Collaboration Rules

- `main`: stable milestone results only
- `dev`: integration branch for reviewed updates
- `maple/*` or `labmate/*`: personal working branches

Recommended workflow:
1. Work in a personal branch
2. Open a pull request into `dev`
3. Review and revise if needed
4. Merge milestone-ready content from `dev` into `main`

## Current Focus

We are currently building and validating a minimal 2D MPPI pipeline, then organizing milestone-level outputs for collaborative writing and future research development.

## Contribution Guideline

When adding milestone content, please include:
- what stage this material belongs to
- where the result comes from
- the main takeaway
- any unresolved questions

## Notes

Raw exploratory work remains in each member's personal study repository.
This shared repository is intended to stay clean, traceable, and writing-friendly.
